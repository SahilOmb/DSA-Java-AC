## 🛠️ Getting Started & Run Instructions

### Prerequisites
Make sure you have the [Java Development Kit (JDK 17 or higher)](https://oracle.comtechnologies/downloads/) installed on your machine.

### Installation & Execution
1. **Clone the repository:**
   ```bash
   git clone https://github.com
   cd YOUR_REPO_NAME
   ```

2. **Navigate to a specific problem or implementation folder:**
   ```bash
   cd "Your_Desired_name"
   ```

3. **Compile and execute the Java file:**
   ```bash
   javac MergeSort.java
   java MergeSort
   ```

## 📊 Standard Complexity Cheat Sheet

Here is a quick look at the benchmarks aimed for during problem-solving:

*   **Logarithmic Time — \(O(\log N)\)**: Binary Search, BST Operations.
*   **Linear Time — O(N)**: Single loops, Hash map insertions, Array traversals.
*   **Linearithmic Time — \(O(N \log N)\)**: Efficient sorting algorithms (Merge Sort, Heap Sort).
*   **Quadratic Time — O(N²)**: Brute-force nested loops (Bubble Sort, Selection Sort).
